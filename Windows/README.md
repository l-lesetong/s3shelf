# s3Shelf Windows 预览版

目标系统为 Windows 10 1607 或更新版本，以及带桌面体验的 Windows Server 2016 或更新版本。需要 Microsoft .NET Framework 4.8 或更新版本，安装程序会检查此依赖。便携版解压后运行 `s3Shelf.exe`。

- 支持 AWS S3 和自定义 S3 端点，可启用路径式访问和 Requester Pays，也可指定首选存储桶或 ARN。自定义 HTTPS 端点支持 PEM 格式的自定义 CA，以及默认为关闭的「忽略 TLS 证书验证」。支持访问密钥、临时会话令牌、AWS Profile 和匿名访问。手动保存的密钥使用 Windows DPAPI 按当前用户加密。
- 从侧栏选择工作区、连接和存储桶。「配置 → 外观」默认跟随系统，也可切换浅色或深色。
- 左右窗格可独立浏览连接、存储桶和路径。对象按页加载，最近 12 个位置的首屏最多缓存 45 秒，路径栏可强制刷新。筛选只检查已加载的条目。
- 详情栏可查看属性和响应头，管理存储桶及当前对象的标签和 ACL。保存前会重新读取服务端数据以检查变更。「配置 → 详情缓存」设置各窗格共享的缓存时间和空间上限，默认 30 秒和 32 MiB，也可选「从不缓存」。命中缓存时显示读取时间，详情栏可强制刷新。
- 支持创建和删除空存储桶。删除桶时需再次输入完整桶名。「配置 → 传输」可设置全局限速和上传分片大小，默认不限速、8 MiB 分片。下载完成后再写入目标文件，进度和结果显示在当前会话的传输历史中。

## 与 macOS 版的功能差异

| 功能 | Windows 当前能力 | macOS 额外能力 |
| --- | --- | --- |
| 连接 | 首选桶或 ARN、私有 CA、按连接配置 TLS 验证、Requester Pays、AWS Profile | IAM Identity Center 登录界面及配置切换 |
| 对象工作区 | 左右双窗格、按页加载、首屏缓存、属性和响应头 | 上下分屏、最多四窗格、历史版本与删除标记、对象预览、会话日志 |
| 存储桶交付 | 桶名创建表单、删除空桶与同名确认 | 创建区域、失败后核对服务端结果与请求详情 |
| 权限和标签 | 存储桶与当前对象的 ACL、标签读写和详情缓存 | 存储桶策略、公开访问阻止、历史版本权限和标签 |
| 传输 | 单文件上传和下载、分片和限速、取消、当前会话历史 | 多任务并发与重试、文件夹同步、批量删除、S3 → S3 Copy/Sync 和同步统计 |
| API | 对象和存储桶界面直接调用 S3 SDK | 六个内置 AWS S3 命令组的 API 工作台 |

## 构建

需要 PowerShell、可构建 .NET Framework 4.8 项目的 MSBuild（或 .NET SDK）和 NSIS 3。Windows 构建机可通过 Visual Studio Build Tools 安装 .NET Framework 4.8 构建工具。

```powershell
.\Windows\build.ps1 -MakeNSIS 'C:\Program Files (x86)\NSIS\makensis.exe'
```

安装包和便携 ZIP 默认输出到仓库的 `outputs/` 目录。日常构建沿用项目版本，产物使用北京时间（UTC+8）命名，格式为 `YYYYMMDD-HHmmss-SSS+0800`。确认发布版本后，可用 `-Version` 指定版本号。安装程序按当前用户安装，卸载后保留当前用户的连接配置。
